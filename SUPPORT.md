# Support

GovHawk is community-supported open-source software. It does not include an SLA,
emergency response, compliance certification, or guaranteed compatibility with
every AWS account configuration.

## Getting help

- Read the [README](README.md), especially Important boundaries, Requirements,
  and Current limitations.
- Review [IAM_PERMISSIONS.md](IAM_PERMISSIONS.md) for required API operations.
- Search existing GitHub issues before opening a new one.
- Use the bug-report template with a minimal synthetic reproduction.

Never attach a real report or disclose credentials, account IDs, resource names,
CUI, classified data, or other environment details in an issue.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and use GitHub's
private vulnerability-reporting feature. Do not file a public security issue.
